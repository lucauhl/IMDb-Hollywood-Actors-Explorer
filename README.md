## How to use the main program:
1. To open the terminal application, run `main.exe`; alternatively you can run `main.py`
2. Ensure that the `database.sqlite` file is in the same directory as both `main.exe` and `main.py`; otherwise the database connection will not work
3. If you are running the `main.py`, ensure you are in the directory where the `database.sqlite` file is located; otherwise the database connection will not work
4. Select an actor from the list of actors by their number or name.
5. Select an option by number.
6. Select one of these options: different actor/actress, show options again, or exit the program; using the numbers 1, 2, or 3

## Required modules to run the `webscraper.ipynb`:
- BeautifulSoup
- selenium
- time
- pandas
- sqlite3
